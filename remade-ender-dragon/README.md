# Remade Ender Dragon

A single optional YVtils module that adds player-scaled End encounters, readable
attack warnings, finite attack budgets, and team support objectives.

- Module/artifact ID: `remade-ender-dragon`
- Display name: **Remade Ender Dragon**
- [Gameplay, configuration, commands and test guide](../docs/remade-ender-dragon.md)

Build with `./gradlew :remade-ender-dragon:build`. Enable
`remade-ender-dragon: true` in `plugins/yvtils/modules.yml`, with the artifact
available through the configured module repository, then restart.

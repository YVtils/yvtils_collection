# GUI — Minecraft 26.3

Version-specific InvUI 2.5.x library selected by core on Paper 26.3.
`build.gradle.kts` compiles the canonical Kotlin sources from
[`gui-26.1`](../gui-26.1/README.md); this folder intentionally has no duplicate source tree.

Provides the same config-editor/control API as the other variants. Keep Paper API,
InvUI and the core registry aligned. Verify with `./gradlew :gui-26.3:build`.
